### SidVault

Local password manager for Windows. One encrypted file on your disk — no server, no account, no network calls. The `.svault` format is documented and ships with an independent reference reader, so your data outlives the software.

`Rust` · `Argon2id` · `TOTP` · `CLI + resident agent`

[**Website**](https://zubulmuk92.github.io/SidVault/) · [Source](https://github.com/zubulmuk92/SidVault) · [Format spec](https://github.com/zubulmuk92/SidVault/blob/main/docs/format-svault.md)

### SidSoundboard

Windows soundboard that costs zero CPU while playing. FFmpeg pre-renders each effect once, so triggering a sound is just a disk stream — and the headset and the virtual cable play the exact same file.

`Python` · `Qt` · `FFmpeg` · `single-file .exe`

[**Website**](https://zubulmuk92.github.io/SidSoundboard/) · [Source](https://github.com/zubulmuk92/SidSoundboard) · [Download](https://github.com/zubulmuk92/SidSoundboard/releases/latest)
